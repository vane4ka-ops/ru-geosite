# Ревизия списков

Списки маршрутизации — контролируемый перечень конкретных сервисов. Массовые
правила для всех `.ru` или `.su` запрещены.

## Удалено из `direct.txt`

- `www.google.com` — иностранный сервис Google;
- `ifconfig.me` — иностранный диагностический сервис;
- `itunes.apple.com` — сервис Apple.

Это соответствует исходному требованию не направлять иностранные сервисы
напрямую без отдельного согласования.

## Требует решения владельца

Эти записи похожи на международные бренды либо требуют подтверждения текущего
владельца/назначения. Они не удалены автоматически, чтобы не сломать нужный
маршрут: `auchan.ru`, `burgerking.ru`, `metro-cc.ru`, `spar.ru`, `t-mobile.ru`.

## Добавления

Автоматически ничего не добавлялось. `proxy.txt` сохраняет два исходных
приоритетных правила FaceTime. Новое правило добавляется только после явного
одобрения владельца в pull request.
